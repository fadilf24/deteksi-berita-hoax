Sistem-Deteksi-Bertia-Hoaks
Tugas Akhir Sistem Deteksi Berita Hoaks untuk kebutuhan skripsi, menggunakan algoritma Naive Bayes untuk klasifikasi dan Large Language Models (LLM) untuk interpretasi hasil prediksi.

Deskripsi Proyek
Sistem ini bertujuan untuk membantu mendeteksi berita hoaks secara otomatis. Data berita diolah menggunakan teknik Natural Language Processing (NLP) untuk mengekstraksi fitur teks, kemudian diklasifikasikan menggunakan Naive Bayes. Selain itu, LLM digunakan untuk memberikan interpretasi dan penjelasan terhadap prediksi yang dihasilkan.

Fitur utama:

Klasifikasi berita hoaks atau bukan hoaks
Interpretasi prediksi menggunakan LLM
Pipeline NLP dari preprocessing hingga prediksi
